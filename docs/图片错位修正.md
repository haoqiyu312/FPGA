# 图片错位修正（2026-10-03）

照片显示横向拼接异常。目前发现缓存写入在256像素批次中会跨越BMP翻转行边界：第640个像素处地址从307199跳到305920。对突发访问接口，这种跳转需要避免。现将顶层frame_read_write的BURST_SIZE显式设为128，每行恰好五批；读缓存批次随之统一为128。

仿真tb_frame_write逐像素验证307200个翻转地址、每批长度和批内地址连续性。旧256设置在像素640检测到批内跳转；新128设置完整通过2400批。

保留修正前代码及bit在docs/backups/display_fix_20261003，便于对照。没有改分辨率，也没有依照片做固定像素平移。还需重新下载实板确认是否消除了横向错位；彩条异常未有照片，不能认定全部异常来自缓存。

## 实板定位结果

HDMI_DIAG不经过SD卡/SDRAM，仍出现同样水平环绕，排除了缓存作为这次错位主因。HDMI_DIAG_SYNC改用video_timing_registered.v，用户实板确认色块与边框恢复正确。该版本使用同步、后沿、有效画面、前沿的扫描顺序，并将HS/VS/DE/坐标统一寄存输出。不能仅凭此实验区分旧扫描排列与组合译码各自的影响，但新的显示时序已实板验证。TF_IMAGE已接入同一模块，需要再次确认照片显示。
