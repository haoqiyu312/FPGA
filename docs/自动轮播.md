# 自动轮播

KEY4(C1)启动/停止自动轮播，KEY2(B2)下一张，KEY3(B1)上一张；KEY1(A2)复位回扫描所得第一张并停止轮播。按实际总数循环，最多32张。按键消抖20ms；长按不连跳。

SW1(C8)、SW2(C7)选择间隔，拨上是1，拨下是0：

| SW2 | SW1 | 展示时间 |
|---|---|---|
| 下 | 下 | 2秒 |
| 下 | 上 | 5秒 |
| 上 | 下 | 10秒 |
| 上 | 上 | 20秒 |

展示时间从照片真正开始显示后计时；加载时停止计时。更改间隔或手动切图后重新计时。加载动画保留；自动轮播下手动切图不会退出自动模式。开关也做20ms稳定采样。

实现位于image_key_control.v，系统时钟50MHz，分别统计秒内时钟与展示秒数，不将整段时间乘成超长计数器。顶层使用show_image反馈作为开始计时条件。

仿真通过轮播启停、加载暂停、四档间隔、KEY1复位，以及原有按键消抖、长按、忙时忽略和双向回绕测试。布局布线检查通过，实际按键和开关需实板确认。

下载release/TF_IMAGE.bit，先PROGRAM_SRAM验证，确认后PROGRAM_FLASH固化。

## SW3方向控制

SW3(C6)拨下为正序（1→2→…→总数→1），拨上为倒序（1→总数→…→2→1）。20ms消抖，方向变化后当前照片的展示时间重新计时。只影响自动轮播，KEY2仍下一张、KEY3仍上一张。

方向、反向回绕、拨码消抖、手动按键独立性和原轮播测试均通过；布局布线建立余量0.128ns、保持余量0.037ns，无违例。实板方向开关效果待确认。
