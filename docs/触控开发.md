## 新模块

- `rtl/touch_menu_hit.v`：渲染和点击共用按钮区域定义。
- `rtl/touch_menu_control.v`：完整触摸样本输入，输出一个时钟周期的动作事件。
- `rtl/touch_menu_overlay.v`：RGB888 菜单覆盖，七个图标，禁用按钮变暗，按住时高亮。

菜单位于当前 640×480 输出的底部 80 行。按钮区域为 `y=[408,472)`，第 n 个按钮（n 从 0 起）的 `x=[8+88*n,88+88*n)`；按钮之间留有 8 像素间隔。

| 动作码 | 图标/用途 | 允许模式 |
|---|---|---|
| 1 | 双矩形：图片/视频切换 | 两种 |
| 2 | 播放/暂停：视频暂停或图片轮播 | 两种 |
| 3 | 上一张 | 图片 |
| 4 | 下一张 | 图片 |
| 5 | 回到开头 | 视频 |
| 6 | 减号：降低音量 | 两种，后续接音频增益 |
| 7 | 加号：提高音量 | 两种，后续接音频增益 |

动作事件尚未连接播放器；特别是音量按钮目前只产生事件，尚未实现音频增益处理。

## 输入契约与误触处理

控制器所有输入必须在 `clk` 域同步。`sample_valid` 表示一次完整样本，坐标、按下状态和多指状态必须同时有效。
坐标必须先映射到显示用 640×480 像素；目前不假定屏幕触控原始量程为 720×720，也不假定屏幕将 HDMI 画面拉伸满屏。
驱动须定期发布按下样本以及明确的松手样本。默认 50 MHz 时钟下，250 ms 无样本会取消当前手势；参数须随时钟频率/驱动刷新率调整，`TIMEOUT_CYCLES` 必须大于 0。

在按钮内按下、一直留在同一按钮内、再松手才产生一次事件；松手坐标不参与判定，因为部分控制器松手时不提供有效坐标。
滑出按钮或切换播放模式会取消手势。长按不会重复，多指取消，失联不会合成点击。
复位、失联、多指或隐藏菜单后，须先收到单指状态下的“无接触”样本，才重新接收按下手势。

后续顶层需将菜单状态一致地传入像素时钟域，并对齐画面坐标/像素流水线。
当前 overlay 为组合逻辑，尚未在播放器像素时钟下做最终时序验证。
