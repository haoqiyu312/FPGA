## 实板测试步骤

1. 保留当前正常的 `TF_MEDIA_COFFEE.bit`，用 BitWriter 将 `TF_MEDIA_SW4_R2.bit` 下载到 SRAM。使用同一张 SD 卡、同一显示器及原先能正常播放的媒体，便于比对。
2. SW4 拨下，分别打开 BMP 和 RV，确认整屏图像、颜色、视频运动及声音，检查有无半屏花屏或发绿。
3. 播放中拨上 SW4，确认状态、文件名和操作提示隐藏，底图、广告字幕与频谱继续正常；拨下恢复。重复切换并确认返回文件菜单后列表仍可见。
4. 复位后分别在 SW4 上 / 下两种初始位置重复打开媒体。若仍异常，记录图片和视频是否都异常、开关位置及复位是否影响现象，再下载咖啡固件复核。
