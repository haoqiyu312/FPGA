# 咖啡商业广告牌演示

本包面向数字广告牌、商业展陈和信息发布场景，采用无品牌咖啡广告主题。所有画面由内置 image_gen 生成，完整提示词见 `media/coffee_ad/prompts.json`；没有下载网站视频，配乐为脚本原创合成。视频是生成画面的慢速镜头动画，不是实拍录像。

## 文件与用途

- `release/coffee_demo/sdcard/COFFEE.RV`：开发板播放，18 秒、3 fps、640×480 RGB332、48 kHz 单声道音轨。
- `release/coffee_demo/sdcard/AD01.BMP`：现磨咖啡广告。
- `release/coffee_demo/sdcard/AD02.BMP`：冰拿铁新品广告。
- `release/coffee_demo/sdcard/AD03.BMP`：咖啡时光与营业时间公告。
- `release/coffee_demo/COFFEE_PREVIEW.webm`：电脑浏览器预览，24 fps；不含 FPGA 动态字幕和频谱。
- `release/coffee_demo/COFFEE_PREVIEW.avi`：MJPEG+PCM 电脑预览，可用支持 AVI 的播放器打开。
- `release/coffee_demo/COFFEE_RGB332.gif`：按 RVF2 实际像素解码的低帧率预览，无声；不含硬件图层。
- `release/coffee_demo/COFFEE_MUSIC.wav`：单独试听配乐。
- `release/TF_MEDIA_COFFEE.bit`：促销字幕固件。此前 `TF_MEDIA_FEATURES.bit` 仍保留原版内置字幕。

电脑预览用于看广告内容；开发板实际播放以 `COFFEE.RV` 为准。RVF2 的 256 色和 3 fps 限制仍然存在，有序抖动用于改善渐变，并不增加视频色深。

## 上板与演示顺序

1. 在 BitWriter 中使用 `release/TF_MEDIA_COFFEE.bit` 做 SRAM 下载；工程仍为 `prj/TF_MEDIA.al`，顶层 `tf_media_top`。这只准备了文件，没有替你实际烧录。
2. 将 `sdcard` 目录内的四个文件直接复制到 FAT32 卡根目录，不要把整个 `sdcard` 文件夹放到根目录后期待自动递归搜索。安全弹出卡后，在开发板断电状态下插卡。
3. 菜单中用 KEY2/KEY3 选中 `AD01.BMP`，短按 KEY4 打开。KEY2/KEY3 切换三张海报，观察三种转场；双按 KEY2+KEY3 切换 100% / 50% / 200% 缩放。
4. 长按 KEY4 返回菜单，选中 `COFFEE.RV` 并短按 KEY4 打开。连接 HDMI 显示器及其音频输出，听配乐并观察右上角频谱；短按 KEY2 可开关频谱。
5. 视频中每约 3 秒依次叠加“今日推荐：现磨咖啡”“香醇现萃，每一口都是好时光”“新品上市，欢迎到店品尝”。短按 KEY3 开关字幕，可直接展示文字和底图是独立图层。
6. 短按 KEY4 暂停 / 继续，观察声音、画面和字幕时间同步暂停。长按 KEY4 返回菜单。

片中三个字幕段循环两次；图像模式仍显示当前缩放比例。营业时间为虚构演示信息，不对应真实门店。

## 可复现生成

```bash
/usr/bin/python3 tools/make_coffee_ad.py --output release/coffee_demo
/usr/bin/python3 tools/validate_coffee_ad.py release/coffee_demo
TD_BIN=/你的TD安装目录/bin/td.sh bash prj/build_tf_media.sh
python3 tools/package_features.py --output-stem TF_MEDIA_COFFEE
```

生成器拒绝覆盖已有结果，重新制作请指定新的输出目录。固件必须重新编译，不能只把旧 bit 文件重命名为咖啡版。

## 验证边界

媒体格式、音轨与固件编译结果分别记录；RTL 仿真及实板测试未执行。不能用电脑预览代替实板验收。
