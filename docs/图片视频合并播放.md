# 图片与视频合并播放器

工程 `prj/TF_MEDIA.al`，顶层 `rtl/tf_media_top.v`，器件 EG4S20BG256。
当前切换改进版为 `release/TF_MEDIA_SWITCH_FIX.bit`，保留按键静音与触控菜单。旧的 `TF_MEDIA.bit`、`TF_MEDIA_TOUCH.bit` 和 `TF_MEDIA_TOUCH_SILENT.bit` 是历史产物，不包含本次组合键切换；原图片和视频独立工程仍可单独编译。

## SD 卡和屏幕

FAT32 卡根目录同时放置原有 640×480、24 位 BMP 图片和 `VIDEO.RV`。
图片沿用原自动目录扫描规则。无声视频使用 RVF1（1–5 fps），带音频视频使用 RVF2（3–5 fps），
两者均为 640×480、RGB332，推荐 3 fps。音频说明见 [视频音频播放](视频音频播放.md)。
无需删除原有图片，无需格式化；MP4 文件不能直接播放，转换方法见 [视频播放](视频播放.md)。
5 秒动态彩条可通过 `python3 tools/make_video_demo.py release/VIDEO.RV --seconds 5 --fps 3 --audio` 生成。

HDMI_B 连接屏幕，屏幕单独按其硬件说明供电。输出仍为 640×480；720×720 原生面板是否
接收并缩放这个输入信号需实测，本版没有改为 720×720 输出。菜单与 GT911 I²C 触控现已接入源码；触控测试版及接线待确认项见 [触控开发](触控开发.md)。
RVF2 音轨通过 HDMI 输出，屏幕耳机口可接有源音箱；暂停、重播及循环同时控制音轨。
图片和旧 RVF1 文件静音，硬件出声效果仍需实测。

## 按键

默认进入图片模式；KEY1 全局复位也回到图片模式。

| 操作 | 图片模式 | 视频模式 |
|---|---|---|
| KEY1 | 复位回第一张，关闭轮播 | 复位回图片模式 |
| KEY2 | 下一张（保留原板程序行为） | 从头播放，解除暂停 |
| KEY3 | 上一张（保留原板程序行为） | 保留 |
| KEY4 短按并松手 | 开启/关闭图片轮播 | 暂停/继续 |
| KEY4 持续按住超过 1 秒 | 切换至视频模式 | 切换至图片模式 |
| KEY4+KEY2 同时按住约半秒后全部松开 | 切换至视频模式 | 切换至图片模式 |

长按实际门限为消抖后的 1 秒，手动操作可按住 2 秒留出余量。原版门限为消抖后的 2 秒，按约 2 秒就松手可能落在门限之前而触发轮播。
组合键仅需连续消抖 20 ms，推荐同时按住半秒，或先按 KEY4 并在一秒内按下 KEY2，然后松开两键。长按已触发后再按 KEY2，不会再次切换。
长按或组合键只切换一次；继续按住或松手不会额外触发短按。组合键必须两键均松开并消抖后才重新接受下一次操作，避免松手顺序导致暂停、轮播或重复切换。
短按在消抖后的松手时生效。模式切换重新初始化读卡和 SDRAM，期间短暂黑屏，
图片从第一张开始且轮播关闭；视频从第一帧开始且未暂停。
不支持热插卡。图片轮播的间隔、方向拨码及中文提示保留。

图片模式数码管显示图片编号与总数；视频模式左边显示读取状态、右边显示目标帧率。
视频错误 10–15 的含义见 [视频播放](视频播放.md)。没有 VIDEO.RV 时仍可切回图片模式；
没有 BMP 图片时也可长按切换到视频模式。

## 下载和测试

1. 复制文件后执行 `sync` 并安全卸载 SD 卡，开发板断电插卡。
2. 上电，在 BitWriter 删除旧列表项，添加 `release/TF_MEDIA_SWITCH_FIX.bit`。
3. 选择 AL-LINK、PROGRAM_SRAM、1 MHz，点击 Run。不要选旧的 TF_IMAGE/TF_VIDEO 文件。
4. 确认图片显示，KEY2/KEY3 切图，短按 KEY4 验证轮播。
5. 同时按住 KEY4+KEY2 约半秒后全部松开，验证视频自动循环；也可只按住 KEY4 2 秒。短按 KEY4 验证暂停/继续，单独 KEY2 验证重播。
6. 再长按 KEY4 回图片模式，重复切换，检查无错行、花屏或卡死。

SRAM 下载断电失效，需重新下载。首次验证不要直接固化 Flash。

## 切换和播放排查

先把 `release/VIDEO.RV`（RVF2，5 秒、3 fps 动态彩条与提示音）复制到 FAT32 卡根目录，安全弹卡后断电插入开发板，再上电下载最新 bit。下载之后不要再次断电，否则可能重新启动 Flash 里的旧图片版。

只开关图片轮播且长时间按住也不切模式：先核对下载的是上述新文件，底部应有七按钮菜单。旧 TF_IMAGE 图片版只有轮播功能。无菜单或重新上电后行为退回旧版，应重新下载最新 SRAM 文件。

切换后先等约 5 秒。视频模式数码管左侧显示读取状态、右侧显示目标帧率 03：11 表示没找到根目录的 VIDEO.RV；12 表示文件格式或长度不符；13 表示簇链异常；14 表示读卡或内存超时。MP4 不能直接播放，也不能只改名为 VIDEO.RV。修正卡内容后需断电插卡、上电并重新下载 SRAM 文件，再切视频。

若要绕开模式切换单独验证视频，可下载历史独立版 `release/TF_VIDEO.bit`，把 `release/VIDEO_SILENT.RV` 复制到卡根目录并重命名为 `VIDEO.RV`；上电下载后自动播放，无需长按。该旧独立版只支持 RVF1 无声视频，也未包含合并版的按键静音改动，不要搭配 RVF2 测试文件。

播放自己的视频，在装有 ffmpeg/ffprobe 的电脑上执行 `python3 tools/convert_video.py input.mp4 VIDEO.RV --fps 3 --audio`，再复制生成的 VIDEO.RV 到卡根目录；推荐先以 3 fps 验证。当前是 640×480、RGB332 的低帧率验证播放器，不支持直接解码 MP4。
