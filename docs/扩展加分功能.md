# 扩展加分功能

当前源码的视频字幕已改为咖啡促销文案，对应 `TF_MEDIA_COFFEE.bit`；旧 `TF_MEDIA_FEATURES.bit` 仍保留通用演示文案。咖啡版的完整媒体与操作见 [咖啡广告演示](咖啡广告演示.md)。

本地扩展版工程：`prj/TF_MEDIA.al`，顶层 `tf_media_top`。下载文件为 [`release/TF_MEDIA_FEATURES.bit`](../release/TF_MEDIA_FEATURES.bit)，以下操作说明适用于扩展功能版本。

## 按键

| 场景 | 操作 | 作用 |
|---|---|---|
| 文件菜单 | 短按 KEY2 / KEY3 | 下一项 / 上一项，松手后生效 |
| 文件菜单 | 短按 KEY4 | 打开选中的图片或视频 |
| 图片播放 | 短按 KEY2 / KEY3 | 下一张 / 上一张，松手后生效 |
| 图片播放 | 同时按 KEY2 + KEY3 | 缩放循环：100% → 50% → 200% → 100%；两键均松开后才能再次触发 |
| 图片播放 | 单独长按 KEY3 约 1 秒 | 开关字幕；松开时不会再切到上一张 |
| 图片播放 | 短按 KEY4 | 原有轮播暂停 / 继续 |
| 视频播放 | 短按 KEY2 | 开关音频频谱 |
| 视频播放 | 短按 KEY3 | 开关字幕 |
| 视频播放 | 短按 KEY4 | 暂停 / 继续视频和音频 |
| 播放中 | 长按 KEY4 约 1 秒 | 返回文件菜单 |
| 任意场景 | KEY1 | 复位；字幕、频谱默认开启，缩放恢复 100% |

切图和字幕、频谱开关分别处理。KEY2+KEY3 组合键即使稍有先后也不会切图；识别到组合键后必须松开两键。视频中该组合键也可切换字幕。

## 图层字幕

画面底部显示 16×16 中文点阵字幕，文字为浅黄色，底板为半透明黑色（底图各颜色分量减半），周围画面正常透过。字幕位于转场和图片图层之上，文件菜单位于最上层。与现有中文状态提示共享双端口字库，不复制整套中文 ROM。

图片字幕显示当前缩放比例。视频内置三段演示字幕，每段占 3 秒的媒体帧数，依次显示欢迎语、图层字幕说明和音频可视化说明。仅在播放器实际接收新视频帧时计数；暂停、等待下一帧时不按墙钟推进。字幕是固件内置示范文本，尚不读取 SD 卡 SRT/ASS 文件，也不是视频对白识别。

演示文案与时序在 `rtl/media_subtitles.v`。修改中文内容还需把新增汉字加入 `tools/generate_osd_font.py` 的 `feature_captions` 并重建字库。字库为编译时资源，运行时无需字体文件。

## 转场特效

每次图片重新加载后，以约 32 个显示帧（约半秒）揭示新画面；按切图次数依次使用：

1. 渐亮：RGB 三通道由黑色逐渐恢复。
2. 横向擦除：从左向右显示新图片。
3. 棋盘分区：交错方块采用水平 / 垂直揭示。

单图片帧缓存方案采用“从黑底揭示新图”，加载时仍显示原有加载提示；不保留上一张图片做双图交叉淡化。转场不作用于视频，不改变字幕、菜单与 HDMI 时序。

## 图片缩放

输入图片格式继续为 640×480、24 位、无压缩、正高度 BMP。HDMI 输出始终保持 640×480：

- 100%：原尺寸。
- 50%：最近邻抽样为 320×240，居中显示，外侧黑边。
- 200%：把原图中心 320×240 区域放大到全屏，最近邻重复像素；边缘裁切。

缩放发生在 SDRAM 读取阶段，所有模式均消费完整 640×480 显示像素流，不新增帧缓存、不重新扫描 SD 卡。参数在垂直消隐和读请求应答阶段锁存，避免一帧内切换比例。视频双缓冲读取地址原样通过，不受图片缩放影响。

## 音频可视化

将已有八频段 Goertzel 分析器接入实际 RVF2 解码 PCM，画面右上角显示八根彩色动态柱。分析器工作在 HDMI 的 48 kHz 采样节拍，八个频带中心约为 750、1500、2250、3000、4500、6000、9000、12000 Hz。720 R2 的源音轨为 12 kHz，6 kHz 以上柱形包含重复采样产生的镜像，不能当作独立高频内容。每 64 个采样更新，显示值在帧边界锁存，下降带衰减。

分析对象是当前视频的真实音轨。图片、无声 RVF1 不显示频谱。暂停时停止送入分析样本，柱形保持。仍不提供 MP3、AAC 等独立音频文件解码。

## 上板验收

1. 打开有明显边框或网格的 BMP，连续按 KEY2+KEY3，确认原图、居中缩小、中心放大三种状态；两键松开后不得意外切到相邻图片。
2. 连续切换至少四次图片，观察渐亮、横向擦除、棋盘分区循环；字幕应位于转场上方。
3. 长按 KEY3 关闭 / 开启图片字幕；播放 RVF2 后短按 KEY3 切换视频字幕。暂停数秒再继续，确认字幕时间没有越过暂停区间。
4. 使用含不同音高的 RVF2 音轨，检查八根频谱柱随音乐变化、KEY2 可关闭、暂停后柱形保持；确认 HDMI 声音与原有播放一致。
5. 长按 KEY4 返回菜单，再打开不同文件，确认菜单、字幕、缩放和音轨状态没有破坏文件切换。
