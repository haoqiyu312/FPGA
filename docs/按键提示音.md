# 按键提示音

当前 TF_MEDIA 合并播放器已关闭按键蜂鸣器：H11 的低有效输出 `buzzer_n` 固定为高电平，KEY1～KEY4 均不发出提示音，HDMI 视频音轨仍正常输出。下载最新 `release/TF_MEDIA_SWITCH_FIX.bit` 后生效；旧静音版 `TF_MEDIA_TOUCH_SILENT.bit` 也保持静音，但没有组合键切换功能。

用户开发板只有四路拨码，没有 SW5，不能使用旧说明中的 SW5 静音方法。

以下说明适用于旧版 TF_IMAGE 独立图片工程；当前 TF_MEDIA 固件不使用该提示音逻辑。

蜂鸣器H11为低电平驱动，空闲输出高电平。key_beeper.v使用50MHz时钟，半周期12500拍，音长3000000拍；提示音独立于KEY1控制的系统复位，保证按KEY1本身仍能发声。快速重叠按键会重新开始短音计时，不排队。



先PROGRAM_SRAM验证release/TF_IMAGE.bit，确认后PROGRAM_FLASH固化。SW6保持拨上选择数码管。
