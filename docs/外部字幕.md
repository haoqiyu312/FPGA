# RV 视频外部字幕

OLED 版本从 TF 卡读取与视频同名的 SRT 字幕。将例如 `FILM.RV` 和 `FILM.SRT` 放在 TF 卡根目录；字幕不显示在媒体列表里，也不计入文件序号。当前仅按 FAT 短文件名查找，建议文件名使用不超过 8 个大写英文字母、数字或下划线。

视频播放时按 S1 开关字幕，S3 开关频谱，S6 暂停/继续，S4 返回菜单。字幕文件缺失时视频仍可正常播放。

## 准备字幕

使用 UTF-8 SRT，并先运行检查工具：

```bash
python3 tools/prepare_srt.py input.srt FILM.SRT
```

当前实现最多处理 16 段字幕，每段最多 32 个 Unicode BMP 字符，文件不超过 32768 字节，字幕时间须在 4 小时内。工具会检查格式、时间重叠、空文本和字库缺字。播放器使用的字库只含界面和项目演示所需字符，不支持任意汉字。

字幕在视频开始前读入缓存；字幕时间随视频实际呈现帧推进，暂停或等待新帧时不前进。字幕切换精度受视频帧率限制，例如 1 fps 视频的精度约为一秒。

`media/SAMPLE.SRT` 是格式示例；复制到 TF 卡时，应按视频基本名重命名为对应的 `.SRT` 文件。
