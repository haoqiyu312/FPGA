## TD 6.2.1 迁移

安装及验证版本为 Release 6.2.1 / Build 175876。工程版本字段使用该工具的 `6.2.175876` 格式，源码编译顺序去重，PLL、加密 HDMI/SDRAM 模块均可被此版本解析和综合。

采用 `derive_clocks` 生成 PLL 时钟约束。启动请求异步置位复位，各时钟域原有三拍移位寄存器同步释放；时序例外仅覆盖 `ready_clock` / `video_ready` 请求进入对应同步器的路径，不排除移位寄存器数据路径或下游复位路径。

6.2.1 完整综合、布局布线和 bit 生成通过，最终建立/保持总负时序均为零。按键/轮播/数码管/透明 OSD、自动扫描、碎片文件与完整 307200 像素读取回归均通过。新版实板运行仍需下载确认。

编译脚本拒绝非 6.2.1 版本，检查新生成 bit 和最终时序报告，并在存在建立或保持违例时返回失败。
