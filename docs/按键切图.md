# 按键切图

KEY1(A2)复位回第一张并关闭轮播；KEY2(B2)下一张；KEY3(B1)上一张；KEY4(C1)开关轮播。独立KEY按下为低电平。

根目录中的BMP不再要求PIC01~PIC04文件名，按实际扫描顺序和总数循环，最多32张。支持640×480、RGB24无压缩、正高度BMP。扩展名大小写均可，不支持的头部自动跳过；无可用图片时不响应切图。

按键20ms消抖，一次按下切一张，长按不连跳；加载期间不切图，两键同时按不切换。切换时复位缓存和读卡逻辑，冷启动等待1秒，之后固定等待10ms再加载；黑色背景中央十二点转圈及屏幕状态文字持续显示，HDMI时钟和同步保持输出。轮播开启时手动切图保留自动模式，并重新计时。每次按键短鸣一次，SW5拨下接通。

image_key_control.v使用5位索引和动态总数，key_debounce.v负责消抖，fat32_bmp_loader.v扫描目录并读取所选文件。KEY1及三次启动自动重试保留。新版功能和验证见自动扫描与屏幕提示.md。
