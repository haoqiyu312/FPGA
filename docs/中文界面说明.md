# 中文悬浮提示

图片显示时文字直接叠在原图上，只有点阵亮点覆盖图片。字符空白、间距和文字区域外保留原图像素，不填充矩形背景。

- 左上角：当前图片的FAT短文件名，例如PIC01.BMP。
- 右上角：当前序号/实际总数，例如01/04。
- 左下角：轮播关闭时只显示“轮播：关闭”；开启时显示“轮播：开启”，下一行显示“间隔：05秒  方向：正序”。方向和间隔按实际设置更新。

位置以640×480画面计：名字从(16,16)开始，序号从(534,16)开始；轮播关闭时状态从(16,452)开始，开启时状态从(16,424)开始，设置在(16,452)。正常文字为淡白色，错误文字为淡红色，没有背景块。

切图完成、开关轮播或文件名变化后，提示约2秒，然后隐藏；只有轮播开启时，更改间隔/方向才会重新弹出提示。初始化、扫描、加载、准备显示和错误信息持续显示在左上角，格式说明或KEY1重试提示显示在左下角。加载时底层仍为黑色转圈动画。

预览见images/中文界面预览.png：左图为轮播关闭，右图为轮播开启；两幅均由实际RTL输出叠加到示例照片后采集。

## 图片名字

fat32_bmp_loader.v扫描目录时保留8字节主名和3字节扩展名，与通过头部验证的图片起始簇/长度一起入表。选图后输出对应的11字节目录短名，OSD去掉填充空格，加入点号，显示basename.ext。文件名经过两级同步，在帧起点锁存。

目前显示FAT的8.3短文件名，支持可打印ASCII字母、数字和符号。长文件名显示其FAT短名别名，例如SUMMER~1.BMP；尚未解析VFAT长文件名或OEM编码中文名称。现有PIC01.BMP至PIC04.BMP可完整显示。

## 字库与对齐

osd_font16.v包含171个UI及可打印ASCII字符的16×16点阵，通过八位字形索引与四位行索引同步读出。字形来自Noto Sans CJK SC Regular，授权声明见licenses/OSD_FONT_OFL.txt。

image_status_osd.v使用16位码点构造中文提示。字库有一拍输出延迟，文字区域、位置和颜色同时延迟一拍。顶层再延迟20拍，与图片和HDMI同步原有21拍延迟对齐。叠加使能只在字形亮点为1时置位。

字库已编入Verilog和bit文件，TF卡只需图片；TD编译无需字体或Pillow。只有重建字体时才需Pillow和字体：

```bash
python3 tools/generate_osd_font.py --font /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc --font-index 2
```

--preview可输出字形预览。新增提示字时同步更新脚本MESSAGES/EXTRA、界面编码并重新生成字库。

仿真通过文件名随选图切换、短名填充去除、小写后缀、三个角落的布局、字形间透明、关闭时隐藏设置、关闭时拨码不弹出无关提示、开启时显示设置、提示隐藏和错误颜色。测试命令bash sim/run_ui_tests.sh及bash sim/run_catalog_tests.sh。实板需下载release/TF_IMAGE.bit确认。
