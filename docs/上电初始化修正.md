# 上电初始化修正

用户实板确认显示时序修正后图片正常，但首次上电红屏，KEY1复位后恢复。红屏表示文件加载器进入错误状态，现有信号没有记录具体错误码，尚不能断定是卡上电速度或其他复位原因。

初始等待从20ms改为1秒；加载器错误位同步至50MHz系统时钟域，持续10ms后自动复位SD/缓存/视频逻辑，等待500ms再启动；最多重试三次，仍失败保留红屏，防止错误格式无限重启。初始化复位移位寄存器显式上电为0；KEY1仍可重新开始。

tf_startup_control.v负责等待和重试。tb_startup.v以缩短计时参数检查无需KEY1的冷启动、等待时间、三次重试上限、按键复位、PLL失锁复位；仿真通过。实际1秒和500ms通过50MHz时钟计数实现。

仍需实板验证首次启动；断电后必须从更新后的Flash启动，或重新下载最新SRAM程序，否则运行的不是此版本。

为给簇地址计算提供充足时序余量，SD解析时钟降为50MHz，PLL VCO仍为1000MHz，缓存40MHz和视频25/125MHz保持原值；SPI分频同步调整，卡侧初始化200kHz与读取12.5MHz不变。
