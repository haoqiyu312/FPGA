## 图片播放与视频播放怎么切换

以下操作适用于 `release/TF_MEDIA_SWITCH_FIX.bit` 合并版。TF 卡使用 FAT32，根目录同时放入图片 BMP 和视频 `VIDEO.RV`。图片须为 640×480、24 位、无压缩、正高度 BMP；视频须预转换为 RVF1（无声）或 RVF2（有声），不能直接播放 MP4。

上电运行合并版后默认进入图片模式，切换时无需重新烧录，也无需更换 TF 卡。

- **图片 → 视频**：同时按住 **KEY4 + KEY2 约半秒**，然后将两键全部松开；程序切换到视频并开始播放。
- **视频 → 图片**：再次同时按住 **KEY4 + KEY2 约半秒**，然后将两键全部松开。
- **单键切换方法**：单独长按 **KEY4 约 2 秒**再松手，也能在两种模式间切换。程序门限约为 1 秒，按住 2 秒更容易操作；持续按住只切换一次。
- **短按 KEY4 不切换模式**：在图片模式开关自动轮播，在视频模式暂停或继续；短按动作在松手后生效。

| 按键 | 图片模式 | 视频模式 |
|---|---|---|
| KEY1 | 复位，回到图片模式 | 复位，回到图片模式 |
| KEY2 | 下一张 | 从头重播视频 |
| KEY3 | 上一张 | 无播放控制动作 |
| KEY4 短按并松手 | 开启/停止自动轮播 | 暂停/继续视频及声音 |
| KEY4 长按约 2 秒 | 切到视频 | 切到图片 |
| KEY4 + KEY2 同时按约半秒 | 切到视频 | 切到图片 |

组合键每次切换后必须松开两键，再进行下一次操作。有声 RVF2 在视频播放时输出 HDMI 音频，暂停时声音也暂停；图片模式和无声 RVF1 不播放音轨。SRAM 下载后须保持供电，断电会加载 Flash 中的程序；需要开机仍运行此版本时，应将同一最新 bit 文件写入 Flash。

## 使用方法

TF 卡格式为 FAT32，将 `media/PIC01.BMP` 至 `PIC04.BMP` 放在根目录。也可以使用自己的图片：必须是 **640×480、24 位 RGB、无压缩 BI_RGB、正高度 BMP**。程序按目录项顺序播放，不按文件名排序，最多收录前 32 张有效图片。

开发板断电插卡，上电后使用 BitWriter 添加 `release/TF_IMAGE.bit`，选择 **AL-LINK、PROGRAM_SRAM、1MHz** 下载。确认画面正常后可使用 **PROGRAM_FLASH、1MHz** 固化同一文件。

| 控件 | 功能 |
|---|---|
| KEY1 | 复位到第一张，并停止轮播 |
| KEY2 / KEY3 | 下一张 / 上一张，加载时忽略切图 |
| KEY4 | 启动 / 停止自动轮播 |
| SW1 / SW2 | 间隔：下下 2 秒；SW1 上 5 秒；SW2 上 10 秒；都上 20 秒 |
| SW3 | 下：正序；上：倒序 |

当前 TF_MEDIA 合并播放器已关闭按键蜂鸣器；用户开发板只有四路拨码，旧版 SW5/SW6 操作说明不适用。HDMI 视频音轨不受影响。

显示间隔从照片真正显示后开始计时，加载期间暂停。KEY2/KEY3 手动切图不会关闭已开启的轮播。图片文件的目录顺序、具体错误及重试行为见 [自动扫描与屏幕提示](docs/自动扫描与屏幕提示.md)。
